# سرمشق — سامانه‌ی آموزش درس‌های مدرسه (MVP)

**واقعاً بفهم، حفظ نکن.** آموزش فصل به فصل و مطابق کتاب درسی رسمی، از پایه هفتم تا کنکور، با معلم هوشمند.
نسخه‌ی فعلی: **پایه یازدهم، رشته ریاضی و فیزیک** فعال است و بقیه‌ی پایه‌ها و رشته‌ها با برچسب «به‌زودی» نمایش داده می‌شوند.

## سیستم طراحی

مرجع: [sarmashgh-brand-ui-brief-fa.md](sarmashgh-brand-ui-brief-fa.md)

| بخش | محل در کد |
|---|---|
| توکن‌های رنگ، فاصله، سایه، تایپوگرافی؛ تم روشن و تاریک | `src/app/globals.css` (کلاس‌هایی مثل `bg-surface`، `text-muted`، `rounded-card`) |
| نام و شعار برند | `src/lib/brand.ts` |
| نشانه‌ی برند (کتاب روشن) و آیکون اپ | `src/lib/logo.ts`، `src/components/Logo.tsx`، `src/lib/app-icon.tsx` |
| تم روشن/تاریک/خودکار | `src/lib/theme.ts`، `src/components/ThemeToggle.tsx` |
| کامپوننت‌های پایه | `src/components/ui/` (Button، Badge، ProgressBar، Spinner) |
| رنگ و آیکون موضوعی کتاب‌ها | `src/components/SubjectIcon.tsx` (فیلد `subject` در `src/lib/catalog.ts`) |
| باکس‌های آموزشی | `src/components/lesson/Blocks.tsx` |

آیکون‌ها از [Lucide](https://lucide.dev) و فونت، وزیرمتن (مجوز SIL OFL) است.

## اجرا روی کامپیوتر خودتان

پیش‌نیاز: Node.js نسخه‌ی ۲۰ یا بالاتر.

```bash
npm install
cp .env.example .env      # بعد AUTH_SECRET را یک رشته‌ی تصادفی بلند بگذارید
npx prisma db push        # ساخت دیتابیس
npm run dev               # http://localhost:3000
```

- **ورود:** تا وقتی `KAVENEGAR_API_KEY` خالی است، کد ورود روی همان صفحه (و در کنسول سرور) نمایش داده می‌شود.
- **چت‌بات:** تا وقتی `AI_BASE_URL` و `AI_API_KEY` و `AI_MODEL` خالی‌اند، چت‌بات در حالت نمایشی جواب ثابت می‌دهد.

## چه چیزهایی در MVP هست

- صفحه‌ی معرفی با همه‌ی پایه‌ها و رشته‌ها (فعال / به زودی)
- ورود با شماره موبایل و کد پیامکی (کاوه‌نگار) + نشست امن (کوکی httpOnly)
- انتخاب نام، پایه و رشته
- داشبورد: «ادامه‌ی یادگیری»، درس‌های اخیر، پیشنهاد مرور (آزمونک زیر ۶۰٪)، کتاب‌ها با پیشرفت؛ ناوبری پایین (خانه، کتاب‌ها، آزمون‌ها، پروفایل)
- حالت روشن، تاریک و خودکار
- صفحه‌ی کتاب: فصل‌ها و درس‌ها با وضعیت (تمام‌شده، نمره‌ی آزمونک، به زودی)
- صفحه‌ی درس: اهداف و پیش‌نیاز، کادرهای تعریف / مثال / اشتباه رایج / نکته‌ی کنکوری، «خودت امتحان کن»، آزمونک با توضیح، دکمه‌ی «تمام کردم»، درس قبل و بعد
- **معلم هوشمند:** پنجره‌ی چت روی هر درس، با دکمه‌ی «این قسمت رو نفهمیدم» در هر بخش و «از معلم بپرس» برای سؤال‌هایی که در آزمونک غلط زده شده. جواب‌ها بر پایه‌ی متن همان درس است و سقف روزانه دارد.
- PWA (قابل نصب روی گوشی، آیکون، کار با اینترنت ضعیف برای صفحه‌های قبلاً بازشده)
- **محتوا:** فهرست کامل فصل‌ها و درس‌های حسابان (۱)، هندسه (۲) و آمار و احتمال؛ فصل‌های فیزیک (۲) و شیمی (۲)؛ و **۵ درس کامل فصل ۱ حسابان (۱)** (جبر و معادله).

## چت‌بات: اتصال به سرویس هوش مصنوعی

کد با هر سرویسی که API سازگار با **OpenAI Chat Completions** دارد کار می‌کند. فقط سه مقدار را در `.env` بگذارید:

```
AI_BASE_URL="https://.../v1"
AI_API_KEY="..."
AI_MODEL="..."
```

⚠️ قبل از انتخاب سرویس، بررسی کنید کدام سرویس‌دهنده **به‌طور قانونی** برای شما و کاربرانتان قابل استفاده است. کیفیت توضیح ریاضی به فارسی را هم با چند سؤال واقعی از درس‌ها مقایسه کنید.

## انتشار

### سرور
- دیتابیس را به PostgreSQL ببرید: در `prisma/schema.prisma` مقدار `provider` را `postgresql` کنید و `DATABASE_URL` را تنظیم کنید.
- برای پایداری در زمان اختلال اینترنت بین‌الملل، میزبانی داخل کشور را در نظر بگیرید.
- متغیرهای `.env` را روی سرور تنظیم کنید. در حالت production، بدون کلید پیامک ورود غیرفعال است.

### آیفون (وب‌اپ)
سایت را با HTTPS منتشر کنید. کاربر در Safari دکمه‌ی Share و بعد **Add to Home Screen** را می‌زند. اپ تمام‌صفحه و با آیکون باز می‌شود.

### اندروید (گوگل‌پلی، کافه‌بازار، مایکت)
همین وب‌اپ با **TWA** (Trusted Web Activity) به فایل اپ اندروید تبدیل می‌شود:
1. سایت را روی دامنه‌ی نهایی با HTTPS منتشر کنید.
2. با ابزار [Bubblewrap](https://github.com/GoogleChromeLabs/bubblewrap) یا سایت PWABuilder، از آدرس `manifest.webmanifest` فایل AAB/APK بسازید.
3. فایل `/.well-known/assetlinks.json` را (که ابزار می‌سازد) در پوشه‌ی `public/.well-known/` بگذارید.
4. فایل را در فروشگاه‌ها منتشر کنید.

## قدم‌های بعدی (پیشنهادی)

1. **بازبینی محتوای فصل ۱ حسابان توسط معلم** و تطبیق با آخرین چاپ کتاب ← بعد `status: reviewed`
2. تست با ۲۰ تا ۵۰ دانش‌آموز واقعی و جمع‌کردن بازخورد
3. نوشتن بقیه‌ی فصل‌های حسابان (۱)، بعد هندسه (۲) و آمار و احتمال
4. پنل ادمین برای ورود محتوا بدون فایل
5. شکل و نمودار در درس‌ها (مثلاً سهمی، محور اعداد)
6. بانک سؤال کنکور و آزمون جامع فصل
7. پرداخت و اشتراک (درگاه داخلی)
