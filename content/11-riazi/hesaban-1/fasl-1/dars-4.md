**قدرمطلق** دقیقاً همین ایده است: فاصله، بدون توجه به جهت. در این درس می‌بینی که با این نگاه، خیلی از مسئله‌های قدرمطلق که در ظاهر سخت‌اند، با یک نگاه به محور اعداد حل می‌شوند.

## تعریف قدرمطلق

روی محور اعداد، **قدرمطلق یک عدد، فاصله‌ی آن عدد تا صفر است.**

- عدد $5$ پنج واحد با صفر فاصله دارد: $|5| = 5$
- عدد $-5$ هم پنج واحد با صفر فاصله دارد: $|-5| = 5$
- و $|0| = 0$

حالا تعریف جبری که در محاسبه‌ها از آن استفاده می‌کنیم:

:::key تعریف قدرمطلق
$$|x| = \begin{cases} x & x \ge 0 \\ -x & x < 0 \end{cases}$$

**به زبان ساده:** اگر عدد مثبت یا صفر است، همان را بنویس. اگر منفی است، **قرینه‌اش** را بنویس (که مثبت می‌شود).
:::

:::mistake «$-x$» یعنی منفی؟
خیلی‌ها فکر می‌کنند $-x$ همیشه منفی است. نه! اگر $x = -4$ باشد، $-x = 4$ مثبت است. در تعریف بالا، $-x$ برای $x$های منفی استفاده می‌شود، پس حاصلش **مثبت** است.
:::

:::example مثال ۱: وقتی علامت داخل معلوم نیست
مقدار این‌ها را بدون قدرمطلق بنویس:
**الف)** $|3 - \pi|$ &nbsp; **ب)** $|\sqrt{2} - 1|$

**الف)** $\pi \approx 3.14$، پس $3 - \pi$ منفی است. طبق تعریف، قرینه‌اش را می‌نویسیم:
$$|3 - \pi| = -(3 - \pi) = \pi - 3$$

**ب)** $\sqrt{2} \approx 1.41$، پس $\sqrt{2} - 1$ مثبت است و همان می‌ماند:
$$|\sqrt{2} - 1| = \sqrt{2} - 1$$

**قاعده‌ی سریع:** $|a - b|$ همیشه برابر است با «بزرگ‌تر منهای کوچک‌تر».
:::

## قدرمطلق تفاضل: فاصله‌ی دو عدد

این مهم‌ترین ایده‌ی درس است:

:::key فاصله‌ی دو عدد
عبارت $|a - b|$ برابر است با **فاصله‌ی $a$ و $b$ روی محور اعداد**.

مثلاً $|7 - 2| = 5$ و $|2 - 7| = 5$؛ فاصله‌ی ۲ و ۷ پنج واحد است، از هر طرف که حساب کنی.
:::

با این نگاه، عبارت $|x - 3|$ را این‌طور بخوان: **«فاصله‌ی $x$ تا عدد ۳»**.
و $|x + 2|$ را این‌طور: $|x - (-2)|$، یعنی **«فاصله‌ی $x$ تا عدد ۲-»**.

## ویژگی‌های قدرمطلق

:::key ویژگی‌های مهم
برای همه‌ی عددهای حقیقی $a$ و $b$:
1. $|a| \ge 0$ (فاصله منفی نمی‌شود)
2. $|-a| = |a|$
3. $|a\,b| = |a|\,|b|$
4. $\left|\frac{a}{b}\right| = \frac{|a|}{|b|}$ (به شرط $b \ne 0$)
5. $|a|^2 = a^2$
6. $\sqrt{a^2} = |a|$
7. $|a + b| \le |a| + |b|$ (نامساوی مثلث)
:::

ویژگی ۶ خیلی مهم است و اشتباه پرتکراری دارد:

:::mistake $\sqrt{a^2} = a$ ؟ نه همیشه!
اگر $a = -3$ باشد:
$$\sqrt{(-3)^2} = \sqrt{9} = 3 \ne -3$$
پس $\sqrt{a^2} = a$ غلط است. درستش $\sqrt{a^2} = |a|$ است.

به همین ترتیب، این‌ها هم **همیشه درست نیستند**:
- $|a + b| = |a| + |b|$ ← مثال نقض: $|3 + (-5)| = 2$ ولی $|3| + |-5| = 8$
- $|a - b| = |a| - |b|$ ← مثال نقض: $|3 - (-5)| = 8$ ولی $|3| - |-5| = -2$
:::

:::example مثال ۲: ساده‌کردن رادیکال
عبارت $\sqrt{(1 - \sqrt{3})^2}$ را ساده کن.

از ویژگی ۶:
$$\sqrt{(1 - \sqrt{3})^2} = |1 - \sqrt{3}|$$

چون $\sqrt{3} \approx 1.73 > 1$، داخل قدرمطلق منفی است:
$$|1 - \sqrt{3}| = \sqrt{3} - 1$$
:::

## معادله‌های قدرمطلقی

معادله‌ی $|x| = 5$ یعنی: «کدام عددها فاصله‌شان تا صفر ۵ است؟» روی محور نگاه کن: **۵ و ۵-**.

:::key حل معادله‌ی $|A| = k$
- اگر $k > 0$: $\quad A = k$ یا $A = -k$
- اگر $k = 0$: $\quad A = 0$
- اگر $k < 0$: جواب ندارد (فاصله منفی نمی‌شود!)
:::

:::example مثال ۳: با نگاه فاصله
$|x - 3| = 5$ را حل کن.

**نگاه فاصله:** کدام عددها ۵ واحد با ۳ فاصله دارند؟ یکی ۵ واحد جلوتر و یکی ۵ واحد عقب‌تر:
$$x = 3 + 5 = 8 \quad \text{یا} \quad x = 3 - 5 = -2$$

**نگاه جبری (همان جواب):**
$x - 3 = 5 \Rightarrow x = 8$ یا $x - 3 = -5 \Rightarrow x = -2$
:::

:::example مثال ۴: قدرمطلق در دو طرف
$|2x - 1| = |x + 2|$ را حل کن.

دو عدد قدرمطلق برابر دارند، یعنی **یا با هم برابرند یا قرینه‌ی هم‌اند**:

**حالت ۱:** $2x - 1 = x + 2 \Rightarrow x = 3$

**حالت ۲:**
$$2x - 1 = -(x + 2) \Rightarrow 3x = -1 \Rightarrow x = -\frac{1}{3}$$

**بررسی $x = 3$:** $|5| = |5| \ ✓$
:::

:::try
معادله‌ی $|3x - 6| = 9$ را حل کن. بعد معادله‌ی $|x + 4| = -2$ را.
---
**اولی:** $3x - 6 = 9 \Rightarrow x = 5$ یا $3x - 6 = -9 \Rightarrow x = -1$
**دومی:** قدرمطلق هیچ‌وقت منفی نمی‌شود، پس **جواب ندارد**. (لازم نیست چیزی حساب کنی!)
:::

## نامعادله‌های قدرمطلقی

باز هم با نگاه فاصله:
- $|x| < 3$ یعنی «فاصله‌ی $x$ تا صفر کمتر از ۳» ← عددهای **بین** ۳- و ۳.
- $|x| > 3$ یعنی «فاصله‌ی $x$ تا صفر بیشتر از ۳» ← عددهای **بیرون** این بازه.

:::key نامعادله‌ها (برای $k > 0$)
$$|A| < k \iff -k < A < k$$
$$|A| > k \iff A > k \ \ \text{یا}\ \ A < -k$$

برای $\le$ و $\ge$ هم همین است، فقط مرزها هم جزو جواب‌اند.
:::

:::example مثال ۵
$|x - 2| < 3$ را حل کن.

**نگاه فاصله:** عددهایی که فاصله‌شان تا ۲ کمتر از ۳ است: از $2 - 3 = -1$ تا $2 + 3 = 5$.
$$-1 < x < 5$$

**نگاه جبری:**
$$-3 < x - 2 < 3 \ \Rightarrow\ -1 < x < 5$$
(به هر سه طرف ۲ اضافه کردیم.)
:::

:::example مثال ۶
$|2x + 1| \ge 5$ را حل کن.

$$2x + 1 \ge 5 \Rightarrow x \ge 2 \qquad \text{یا} \qquad 2x + 1 \le -5 \Rightarrow x \le -3$$

جواب: $x \le -3$ یا $x \ge 2$
:::

:::konkur دو نکته‌ی تستی
1. $|x| = x \iff x \ge 0$ و $|x| = -x \iff x \le 0$
2. وقتی در تست دیدی $|x - a| < k$، بلافاصله بگو: «بازه‌ای به مرکز $a$ و شعاع $k$»؛ یعنی $(a - k,\ a + k)$.
:::

## خلاصه در یک نگاه

| عبارت | معنی |
|---|---|
| $\lvert x \rvert$ | فاصله‌ی $x$ تا صفر |
| $\lvert a - b \rvert$ | فاصله‌ی $a$ و $b$ |
| $\sqrt{a^2}$ | $\lvert a \rvert$ (نه $a$!) |
| $\lvert A \rvert = k > 0$ | $A = \pm k$ |
| $\lvert A \rvert = k < 0$ | جواب ندارد |
| $\lvert A \rvert < k$ | $-k < A < k$ |
| $\lvert A \rvert > k$ | $A > k$ یا $A < -k$ |

## آزمونک

:::quiz
حاصل $|3 - \pi|$ کدام است؟
- $3 - \pi$
+ $\pi - 3$
- $\pi + 3$
- $-3 - \pi$
---
چون $\pi > 3$، عبارت $3 - \pi$ منفی است و قدرمطلقش قرینه‌ی آن است: $\pi - 3$.
(قاعده: بزرگ‌تر منهای کوچک‌تر.)
:::

:::quiz
جواب‌های معادله‌ی $|x + 1| = 4$ کدام است؟
- $3$ و $5$
- فقط $3$
+ $3$ و $-5$
- $-3$ و $5$
---
$|x + 1|$ یعنی فاصله‌ی $x$ تا $-1$. عددهایی که ۴ واحد با $-1$ فاصله دارند: $-1 + 4 = 3$ و $-1 - 4 = -5$.
:::

:::quiz
مجموعه‌جواب نامعادله‌ی $|x - 1| \le 2$ کدام است؟
- $x \le 3$
+ $-1 \le x \le 3$
- $x \le -1$ یا $x \ge 3$
- $1 \le x \le 3$
---
عددهایی که فاصله‌شان تا ۱ حداکثر ۲ است: از $1 - 2 = -1$ تا $1 + 2 = 3$.
گزینه‌ی «$x \le -1$ یا $x \ge 3$» جواب $|x - 1| \ge 2$ است.
:::

:::quiz
کدام رابطه برای **همه‌ی** عددهای حقیقی $a$ و $b$ درست است؟
- $|a + b| = |a| + |b|$
- $\sqrt{a^2} = a$
+ $|a\,b| = |a|\,|b|$
- $|a - b| = |a| - |b|$
---
فقط ضرب و تقسیم با قدرمطلق «جابه‌جا» می‌شوند. مثال نقض برای بقیه:
- $|3 + (-5)| = 2 \ne 8$
- $\sqrt{(-3)^2} = 3 \ne -3$
- $|3 - (-5)| = 8 \ne -2$
:::

:::quiz
معادله‌ی $|2x - 4| = -3$ چند جواب دارد؟
+ جواب ندارد
- یک جواب
- دو جواب
- بی‌شمار جواب
---
قدرمطلق یعنی فاصله، و فاصله هیچ‌وقت منفی نمی‌شود. پس هیچ $x$ای پیدا نمی‌شود که $|2x - 4|$ برابر $-3$ شود.
:::
